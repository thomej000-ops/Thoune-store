# Thoune Store — Protótipo

Protótipo visual e funcional inicial da nova identidade da Thoune Store.

## Arquivos
- `index.html` — estrutura da loja
- `style.css` — identidade visual responsiva
- `app.js` — catálogo, filtros, favoritos, carrinho e cópia do pedido
- `assets/thoune-brand.jpg` — imagem de marca enviada pelo proprietário

## Próxima fase
Este protótipo ainda não é o sistema final.
A próxima etapa é conectar o projeto ao Supabase para:
- produtos reais;
- estoque real;
- pedidos;
- pagamento Pix;
- status online/offline;
- autenticação do administrador;
- configurações de Pix;
- usuário/bot de entrega;
- confirmação manual de pagamento;
- baixa de estoque somente após confirmação.

Nunca coloque a chave `service_role` do Supabase no código público do GitHub.
